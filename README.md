## Complexity Analysis

For algorithms and problem solutions, I try to analyze:

### Time Complexity

How the running time grows with the size of the input.

Common complexities include:

```text
O(1)
O(log n)
O(n)
O(n log n)
O(n²)
O(2ⁿ)
O(n!)
```

### Space Complexity

How much additional memory an algorithm requires.

Understanding complexity is an important part of deciding whether a solution is actually efficient.
